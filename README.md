# Sistema Integral de Gestión - Software FJ

Proyecto desarrollado en Python utilizando Programación Orientada a Objetos.

## Características

- Gestión de clientes
- Gestión de servicios
- Gestión de reservas
- Manejo de excepciones
- Herencia
- Polimorfismo
- Encapsulación
- Logs de errores

## Servicios

- Reserva de salas
- Alquiler de equipos
- Asesorías especializadas
